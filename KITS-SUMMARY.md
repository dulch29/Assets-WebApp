## 🚀 Quick Start

### 1. Browse a Kit
```bash
cd kits/button-system
open index.html
```

### 2. Copy Components
```bash
cp kits/button-system/components/buttons.css your-project/
```

### 3. Use in HTML
```html
<link rel="stylesheet" href="buttons.css">
<button class="hq-btn hq-btn-primary">Click Me</button>
```

## 🎨 Design System

**Color Palette:**
- Surfaces: 5-step dark gradient (#05070C → #1E2636)
- Accents: Cyan (#38BDF8), Emerald (#6EE7B7)
- Text: Primary (95% white), Secondary (70% white)

**Typography:**
- Fluid sizing with `clamp()`
- System font stack
- Negative tracking on headings

**Layout:**
- Grid-first (CSS Grid for structure)
- Flexbox for components
- Fully rounded (999px pills, 50% circles)

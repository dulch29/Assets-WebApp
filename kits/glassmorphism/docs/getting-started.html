🚀 Quick Start Options

Option 1: Use the Full Demo

Perfect for learning or prototyping:

  1. Open index.html or hotel-booking.html in your browser
  2. Inspect with DevTools to see how everything works
  3. Customize colors, content, and structure

Option 2: Extract Individual Components

Recommended for adding to existing projects:

  1. Open the EXTRACT-*.css file for your component
  2. Copy the CSS variables to your :root section
  3. Copy the component CSS styles
  4. Copy the HTML structure (in comments)
  5. Copy the JavaScript (if needed for modal/navbar)

Option 3: Study from HTML

Best for understanding the full implementation:

  1. Open index.html in your code editor
  2. Look for ===== START: HQ GLASS [COMPONENT] ===== comments
  3. Copy everything between START and END markers
  4. Paste into your project

🎨 Component Breakdown

1️⃣ Glass Card

File: EXTRACT-glass-card.css

Use for: Product cards, profile cards, blog previews, feature blocks

Includes:

  • Image placeholder (replace with real images)
  • Title, subtitle, description
  • Tag system for metadata
  • Primary and secondary action buttons
  • Hover animations
⚠️ Important: Cards need a colorful/patterned background to show the blur effect properly.

2️⃣ Glass Modal

File: EXTRACT-glass-modal.css

Use for: Contact forms, login/signup, confirmations, popups

Includes:

  • Backdrop blur overlay
  • Form fields with focus states
  • Close button with animation
  • Primary and secondary action buttons
  • Keyboard support (Escape key closes)
⚠️ JavaScript Required: Modal needs JS for open/close functionality.

3️⃣ Glass Navbar

File: EXTRACT-glass-navbar.css

Use for: Site navigation, sticky headers

Includes:

  • Sticky positioning (stays at top)
  • Responsive mobile menu (hamburger below 768px)
  • Link hover animations
  • CTA button
  • Logo/brand area
⚠️ JavaScript Required: Mobile menu toggle needs JS.

🛠️ Step-by-Step Integration

Step 1: Choose your component — open the corresponding EXTRACT-*.css file
Step 2: Copy CSS variables to your stylesheet's :root section (only once, shared by all components)
Step 3: Copy the component's CSS styles to your stylesheet
Step 4: Copy the HTML structure from the comments in the CSS file
Step 5: If the component needs JavaScript (modal, navbar), copy the JS from the comments
Step 6: Test on a colorful background to see the glass effect in action
✅ Done! Your component is ready. Customize colors by changing --accent-primary in the CSS variables.

🎨 Customization Guide

Change Accent Color

Edit these variables in your CSS:

--accent-primary: hsl(270, 70%, 55%); → Purple
--accent-primary: hsl(160, 80%, 45%); → Green
--accent-primary: hsl(25, 95%, 55%); → Orange

Adjust Blur Intensity

--glass-blur: 16px; → Default
--glass-blur: 8px; → Subtle
--glass-blur: 24px; → Strong

Change Background Opacity

--glass-bg: rgba(255, 255, 255, 0.08); → Lighter
--glass-bg: rgba(255, 255, 255, 0.05); → More transparent

🐛 Troubleshooting

Blur not working?
- Make sure you have both backdrop-filter and -webkit-backdrop-filter
- Test on a colorful background (blur needs content behind it)
- Check browser support (Chrome 76+, Safari 9+, Firefox 103+)
Mobile menu not toggling?
- Verify JavaScript is included at the bottom of your HTML
- Check that element IDs/classes match exactly
- Look for JavaScript errors in browser console
Components look broken?
- Make sure CSS variables are in :root section
- Verify all class names match (they're prefixed with hq-glass-*)
- Check that HTML structure matches the template exactly

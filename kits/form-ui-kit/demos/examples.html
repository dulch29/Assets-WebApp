1. Login Form

Please enter a valid email address.
Password must be at least 8 characters. 
// Students wire their own validation
const form = document.querySelector('#login-form');

form.addEventListener('submit', async (e) => {
    e.preventDefault();

    const email = form.querySelector('#login-email').value;
    const password = form.querySelector('#login-password').value;

    // API call (students write this)
    const response = await fetch('/api/login', {
        method: 'POST',
        body: JSON.stringify({ email, password })
    });
});

6. Form Validation (Interactive)

Must be 3-20 characters. Username must be at least 3 characters long. Username is available!
Password must be at least 8 characters. Strong password! 
// Live validation example
const input = document.querySelector('#demo-username');
const group = document.querySelector('#username-group');

input.addEventListener('input', () => {
    group.classList.remove('has-error', 'has-success');

    if (input.value.length < 3) {
        group.classList.add('has-error');
    } else {
        group.classList.add('has-success');
    }
});
